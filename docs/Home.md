# Welcome to the FamilyRisk Wiki!

FamilyRisk is a unified platform for genomic data anlaysis regarding carrier screening and newborn screening. It also integrates a comprehensive knowledge database for screening strategies, gene-disease panels, and clinical outcomes. \
This Wiki provides detailed tutorials for the core functions of FamilyRisk in terms of carrier screening or newborn screening, helping you efficiently interpret the genomic data and create clinical reports.
